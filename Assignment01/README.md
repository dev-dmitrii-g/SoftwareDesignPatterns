# Assignment 1 (Builder Pattern)

Implementation of network packet using builder pattern.

## Architecture
1. Object representation: Network Packet object.
2. Hex Dump representation: Network Packet hex dump debug log.

## Prerequisites
- Java JDK 26
- Git

## How to run
1. Clone the repository via `git clone`
2. Navigate to the project directory via `cd`
3. Compile the source code via `javac -d bin src/*.java`
4. Run the application via `java -cp bin Main`
